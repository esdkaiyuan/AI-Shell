3. DATA STORAGE AND PRIVACY
────────────────────────────────────────────────────────────────────────

3.1  Configuration data, session records and command history are stored in
     your local application data directory and are never uploaded
     automatically to any server.

3.2  AI provider API keys you enter are encrypted with the operating
     system's secure storage mechanism before being saved (Windows Credential
     Manager / DPAPI, macOS Keychain). Where the operating system offers no
     secure storage, the key is stored in plain text in the local
     configuration.

3.3  When you use the AI assistant, your questions, any attached terminal
     context and command-history lookups are transmitted to the AI service
     provider you configured yourself (possibly OpenAI, Anthropic,
     DeepSeek, Ollama or another third party). This transmission is
     triggered by you; the Software does not forward your data to any fixed
     server of its own.

3.4  AI responses are produced by third-party models and may contain errors.
     Do not execute AI-suggested commands without verifying them first.

3.5  The remote connection (SSH) feature opens an encrypted connection to
     the host you specify. Host, port, username and credentials are stored
     locally only.
