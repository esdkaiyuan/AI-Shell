# Agent 自主执行模式

署名：`esdkaiyuan`

Agent 模式让 AI 助手从「给建议」升级为「把活干完」：它可以自己列目录、读文件、执行命令、查历史命令，看到结果后继续推理，直到任务完成。

## 1. 开启方式

| 方式 | 操作 |
| --- | --- |
| 面板开关 | AI 助手面板右上角 `AGENT` 按钮 |
| 快捷键 | `Ctrl+Shift+G`（macOS 为 `⌘⇧G`），同时会打开 AI 面板 |
| 默认开启 | 设置 → 通用设置 → Agent 自主执行 → 勾选「AI 助手默认使用 Agent 模式」 |

关闭开关即回到普通问答模式，两种模式共用同一份对话历史与会话列表。

## 2. 工作方式

Agent 循环运行在主进程：

```
用户任务 → 模型推理 → 解析工具调用 → 执行工具 → 结果回灌 → 再次推理 … → 最终结论
```

工具调用采用**协议化 tool calling**：模型需要调用工具时输出一个 `tool` 围栏包裹的 JSON 块，核心层解析后交给执行层，结果以 `[工具结果]` 消息回灌。这样不依赖各厂商互不兼容的原生 function calling，项目接入的 9 个提供商（OpenAI / Claude / DeepSeek / GLM / Moonshot / 通义 / Ollama / 文心 / 星火）都能充当 Agent，也便于纯逻辑单测。

模型不再输出工具块时视为任务完成，最终结论写入当前对话并持久化。

## 3. 内置工具

| 工具 | 作用 | 风险 |
| --- | --- | --- |
| `list_directory` | 列出目录内容 | 只读 |
| `read_file` | 读取文本文件 | 只读 |
| `get_terminal_context` | 获取当前终端最近输出 | 只读 |
| `search_history` | 搜索历史命令与退出码 | 只读 |
| `run_command` | 执行一条 shell 命令并返回 stdout/stderr/退出码 | **写操作** |
| `write_file` | 写入（或覆盖）文本文件 | **写操作** |

## 4. 安全边界

| 机制 | 说明 |
| --- | --- |
| 路径白名单 | 所有文件操作与命令工作目录必须位于工作区或用户主目录内，与资源管理器共用同一套校验 |
| 危险命令拦截 | 递归删除根目录、格式化磁盘、写块设备、fork 炸弹、关机重启、删注册表等命令直接拒绝 |
| 人工确认 | 写操作默认弹出确认框，展示工具名与完整参数；拒绝后结果回灌给模型，让它改用只读方式 |
| 资源上限 | 命令 30 秒超时、输出 64KB 截断、单文件 1MB、写入 512KB、目录最多 200 项 |
| 循环防护 | 单任务最多 12 步（可在设置里调整 3–30），同一工具同参数重复 3 次判定死循环并终止 |
| 随时中断 | 轨迹栏停止按钮 / 输入框停止按钮通过 `AbortSignal` 真正中断模型请求与命令进程 |
| 确认超时 | 60 秒未响应按「拒绝」处理，不会悬挂等待 |

自动执行开关默认关闭。开启后写操作不再逐次确认，请仅在可信环境中使用。

## 5. 配置项

设置 → 通用设置 → Agent 自主执行：

- `agentMode` — 是否默认以 Agent 模式打开
- `agentAutoApprove` — 写操作是否免确认
- `agentMaxSteps` — 单任务最大推理步数

配置持久化在 `localStorage`，AI 面板与设置页双向同步。

## 6. 已知限制

- 终端上下文在**任务发起时**注入一次；任务执行期间新产生的终端输出不会自动同步给 Agent（模型可主动调用 `get_terminal_context` 获取发起时的快照）。
- `run_command` 是非交互执行，不支持 `vim`、`ssh` 密码输入、交互式 REPL 等需要 TTY 的命令；这类操作请在终端标签中手动完成。
- Agent 目前仅用于桌面端；手机端 AI 页面仍是本地状态模拟，未接入真实工具执行链路。
- 工具协议依赖模型稳定输出合法 JSON；格式错误会被回灌要求自我修正，但能力较弱的模型可能需要多轮才收敛。
