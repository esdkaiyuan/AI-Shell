# AI Shell UI 设计规范

本文描述当前桌面端与移动端实际采用的设计系统。完整改版目标见
[全端沉浸式工作台规格](superpowers/specs/2026-10-27-all-pages-redesign-design.md)。

## 1. 设计原则

1. **内容优先**：终端输出、AI 对话和任务表单占据主要视觉空间。
2. **单一强调色**：系统蓝只用于主操作、当前选中和实时状态。
3. **中性深色层次**：通过表面明度、留白和细分隔线建立层级，不使用大面积渐变。
4. **统一语义**：桌面与移动共享颜色角色、状态语言和组件含义。
5. **真实状态**：不使用模拟指标、虚假连接状态或成功样式掩盖错误。

## 2. 色彩

### 表面

| 角色       | 色值                     | 用途                         |
| ---------- | ------------------------ | ---------------------------- |
| 页面背景   | `#0a0a0b`                | 窗口、终端、页面空白         |
| 工具栏     | `#141416`                | 顶栏、状态栏、次级 chrome    |
| 面板       | `#1c1c1e`                | 卡片、设置分组、消息气泡     |
| 提升表面   | `#2c2c2e`                | 工具按钮、输入辅助、次级操作 |
| 柔和边界   | `rgba(255,255,255,0.08)` | 分隔线和卡片边界             |
| 强调色     | `#0a84ff`                | 主按钮、选中、链接           |
| 强调柔和底 | `rgba(10,132,255,0.16)`  | 选中背景、图标底             |

### 文字与状态

| 角色     | 色值      |
| -------- | --------- |
| 主文字   | `#f5f5f7` |
| 次文字   | `#a1a1a6` |
| 辅助文字 | `#98989d` |
| 成功     | `#30d158` |
| 警告     | `#ff9f0a` |
| 错误     | `#ff453a` |
| 信息     | `#64d2ff` |

辅助文字在面板上的对比度应保持在约 5:1 以上；不要使用旧版三级灰 `#6e6e73` 承载小字号说明。

## 3. 间距与圆角

- 间距：4 / 8 / 12 / 16 / 24 / 32 px。
- 控件圆角：8–10px。
- 卡片圆角：12–14px。
- 独立面板/弹窗：16px。
- 按钮、状态徽章使用胶囊圆角。
- 桌面内容页常用 20–24px 外边距；移动页面常用 16px。

## 4. 字体

- 系统字体：`-apple-system`, `SF Pro`, `Segoe UI`, `PingFang SC`, `Microsoft YaHei`。
- 等宽字体：`SF Mono`, `Cascadia Code`, `Consolas`, `JetBrains Mono`。
- 桌面正文 13px；辅助说明 11–12px；页面标题 18px；设置内容标题 22px。
- 移动正文 13–14px；辅助说明 10.5–12px；页面标题 18px；向导标题 26px。
- 终端、命令、路径和代码统一使用等宽字体。

## 5. 布局

### 桌面端

- 48px 顶部工具栏、64px 左侧工作轨、底部状态栏。
- 主页面使用统一标题区：标题、上下文副标题、页面操作。
- 终端为连续工作面；文件为路径工具栏 + 列表；AI 为最大 860px 阅读列。
- 管理弹层为居中 Sheet，标题栏固定、正文滚动、操作靠近对应内容。
- 800px 宽度下工具按钮收起文字，仅保留图标和提示。

### 移动端

- 顶部：返回/品牌、页面标题、上下文副标题、页面相关状态。
- 底部五项导航：终端、AI、文件、SSH、我的。
- 会话、历史、设置作为“我的”二级页面。
- 终端标签高度 44px；超出横向滚动。
- 输入区、底部导航和安全区保持可见。

## 6. 组件

### 按钮

- 主操作：系统蓝底、白字，最小高度 44px（移动）。
- 次操作：提升表面或透明底。
- 危险操作：红色文字或淡红背景，必须二次确认。
- 桌面显示 `:focus-visible` 焦点环；移动使用按压态。

### 状态

- 状态同时使用文字和颜色，不能只依赖颜色。
- 运行状态使用中文：待连接、启动中、已连接、已结束、失败。
- 连接失败与配置缺失在发生位置附近展示说明。

### 列表

- 移动列表行最小高度 56–68px。
- 桌面文件行 36px，选中使用浅色底，不使用高饱和整行蓝。
- 文件、SSH、会话和 Provider 卡片中的删除操作需阻止外层点击冒泡。

### 弹层与菜单

- 桌面弹层使用 `role="dialog"`、`aria-modal`、关闭按钮标签和 Escape 关闭。
- 模型、会话、SSH 下拉菜单受视口边界约束。
- 快捷键录制期间，macOS 原生菜单加速器临时挂起。

### 空状态

- 空状态说明当前为什么为空，并提供一个直接操作。
- 不使用装饰性假数据。
- 安装、连接、加载和错误状态复用统一文案。

## 7. 快捷键

- Windows/Linux 使用 Ctrl；macOS 使用 Command。
- macOS 的 Control 组合保留给终端，不注册为应用快捷键。
- 页面内显示平台化符号：`⌘`、`⌥`、`⇧`。
- 自定义快捷键需要冲突检测、默认恢复和方案保存。

## 8. 响应式与可访问性

- 桌面验收宽度：800、1280、1440px。
- 移动验收宽度：360、390、430px。
- 移动触控目标至少 44px；嵌套关闭按钮使用 `hitSlop`。
- 页面无横向溢出；长文本可换行或截断，操作不因换行遮挡。
- 动画简短，并尊重 `prefers-reduced-motion`。
- 图标按钮提供 `aria-label` 或 `accessibilityLabel`。

## 9. 禁止项

- 不使用 emoji 充当界面图标。
- 不使用大面积彩色渐变制造层级。
- 不在控制台日志、错误文案或截图中输出完整密钥。
- 不用“已提交”描述为“执行成功”。
- 不为视觉效果引入模拟终端输出、模拟 AI 回复或模拟连接状态。
